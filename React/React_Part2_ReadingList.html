Part 2, brought up to date with React 19

For each section of Part 2 this page tells you two things: what has changed since Jonas recorded the video, and what to read alongside it. Every link is current official React documentation. Nothing here describes an older version of React.

How to use it: do the setup steps once, then before each section read its "changed since the video" box and its three or four links. Fourteen links, about four hours in total.

Set the project up this way instead of what the video types

First run node -v. Vite needs Node 20.19 or newer. Your Part 3 page needs 22.22, so install that now and you are covered for both.

  1. usePopcorn · instead of create-react-app npm create vite@latest

    It asks three questions. Framework: React. Variant: JavaScript, not "JavaScript + React Compiler". Linter: ESLint, not Oxlint, so the warnings carry the same names Jonas shows.

    You start the app with npm run dev rather than npm start.

  2. Jonas's starter files · rename two of them index.js → main.jsx   App.js → App.jsx

    Vite only accepts JSX in files ending in .jsx. A .js file with JSX in it stops the app with "JSX syntax is disabled". The same goes for StarRating and any component file you create yourself.

  3. Lint warnings · section 10 onward npm run lint

    Create React App printed warnings such as "missing dependency" in the terminal and the browser. Vite does not. Run this command, or install the ESLint extension in VS Code to see them underlined as you type.

  4. Section 8 · you can skip this one npm i prop-types

    React 19 ignores PropTypes completely. Details are in the section 8 box below.

  5. Movie data · sections 10 and 11 omdbapi.com/apikey.aspx

    Same as the video. The free key is still offered, limited to 1,000 requests a day, and arrives by email. Jonas's fetch URL works as he types it.

Ticks are saved in this browser only. Section numbers match your Part 3 page; Udemy's sidebar may show them as 10 to 13.

Section 12, class-based React, is optional in the course and has no reading here. Class components still run in React 19, but the React docs list them under legacy APIs.

You Might Not Need an Effect, which was on the earlier version of this page, is on your Part 3 page under section 16. Read it there, or straight after section 10 if you prefer.
