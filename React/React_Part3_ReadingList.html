Part 3, brought up to date with React 19

For each section of Part 3 this page tells you two things: what has changed since Jonas recorded the video, and what to read instead. Every link is current official documentation. Nothing here is about a deprecated or abandoned tool.

How to use it: do the install steps once, then before each section read its "changed since the video" box and its one to four links. Fourteen links, about three hours in total.

Install these instead of what the video types

First run node -v. You need Node 22.22 or newer for the current React Router. If yours is older, update Node before starting.

  1. Every new project · instead of create-react-app npm create vite@latest

    Create React App was retired in February 2025. Vite is what Jonas himself switches to for WorldWise. Your entry file is src/main.jsx rather than src/index.js.

  2. Fake API · React Quiz and WorldWise npm i json-server@0.17.4

    This is the latest stable release. Plain npm i json-server gives you a 1.0 beta that has no --delay option, so Jonas's start script fails on it.

  3. Routing · instead of react-router-dom npm i react-router

    The react-router-dom package no longer exists in the current version. Wherever Jonas writes from "react-router-dom", write from "react-router". Everything else in his routing code stays the same.

  4. Map · WorldWise npm i react-leaflet leaflet

    Same command as the video. The current version needs React 19, which a new Vite project already has.

  5. Redux · instead of redux, redux-thunk and redux-devtools-extension npm i @reduxjs/toolkit react-redux

    Redux Toolkit already contains thunks and the DevTools connection. If you want to type along with the older createStore lectures as well, add npm i redux redux-thunk and write import { thunk } from "redux-thunk" (with braces).
